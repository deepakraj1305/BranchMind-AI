# BranchMind AI

**BranchMind AI** is a responsive branching-conversation interface. It lets users explore a conversation path, start an alternative branch from any earlier message, view a simple conversation map, and export a session as JSON.

> This is an independently written demo inspired by the general idea of tree-based conversations. It is not a copy of the referenced repository. The current demo uses local example responses and does not connect to an AI model.

## Features

- Responsive chat workspace
- Branch from any message in the current conversation
- Conversation map view
- Multiple conversations saved in browser `localStorage`
- Export a conversation to JSON
- Copy individual messages
- Example prompts to try the demo
- No API key or backend required

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Browser Local Storage API
- Browser Clipboard and Blob APIs

## Run Locally

1. Download and extract the ZIP.
2. Open `index.html` in your browser, or use the VS Code Live Server extension.
3. Start a new conversation and try one of the example prompts.

No package installation is needed for the demo.

## Deploy to Vercel

1. Create a GitHub repository named `BranchMind-AI`.
2. Upload the extracted project files to the repository root.
3. Visit [Vercel](https://vercel.com/new) and import the GitHub repository.
4. Keep the default static-site settings and deploy.
5. Open the URL provided by Vercel.

The actual live demo URL is assigned by Vercel after deployment; it is not included as a pre-created link in this source package.

## Push with Git

Run these commands from the extracted project folder after creating an empty repository on GitHub:

```bash
git init
git add .
git commit -m "Add BranchMind AI branching chat demo"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/BranchMind-AI.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.

## Important Notes

- Conversation history is stored only in the current browser.
- The local demo responses are illustrative, not generated by a live AI service.
- Do not place API keys or passwords in frontend JavaScript.
- If you extend this project with an AI provider, add a server-side API route and store credentials as deployment environment variables.
